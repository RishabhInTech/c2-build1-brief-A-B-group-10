# Brief A/B summary outputs

These compact CSVs were generated from the full local cleaned tables by `analyze_brief_a_b_migration.py`. The underlying patient-level and booking-level data are not included here.

| File | Grain | Contents |
|---|---|---|
| `brief_a_h1_overall.csv` | Six-city H1 total | Actual growth, implied plan growth, attainment and variance |
| `brief_a_b_city_summary.csv` | City | H1 test lines, year-over-year change, plan attainment and variance |
| `brief_a_b_group_plan.csv` | Treated/control group | H1 actual versus plan |
| `brief_a_b_period_summary.csv` | Group and Jan–Mar/Apr–Jun period | Matched-year growth, post gap and descriptive difference-in-differences |
| `brief_a_b_monthly_treated.csv` | Migration city-month | Matched-year counts, plan gap, channel counts and source-system mix |
| `brief_a_b_channel_summary.csv` | Dimension and category | H1 clinic/home and app/phone/walk-in counts |
| `brief_a_b_join_diagnostics.csv` | Year, group and source system | Booking-level collection joins and test-line-level result joins |

Regenerate with the command in [`docs/brief-a-b-analysis.md`](../docs/brief-a-b-analysis.md). The input directory must contain the cleaned CSV tables. These aggregate files contain no patient names or patient IDs.

## Brief D: clinic no-shows

Generated by `analyze_brief_d_no_shows.py` from the full local cleaned tables. One row is one distinct appointment booking. Bookings with no usable collection outcome are counted separately, not called no-shows.

| File | Grain | Contents |
|---|---|---|
| `brief_d/brief_d_clinic_rates.csv` | Clinic | Known-outcome denominator, no-shows, raw Wilson interval, missing-outcome sensitivity bounds, case-mix peer comparison and conditional shuffle p-values |
| `brief_d/brief_d_case_mix.csv` | Clinic, factor and category | Outcome counts/rates by channel, test-count band, slot-time band, weekday type and month for the two clinics highlighted in the report |
| `brief_d/brief_d_monthly_clinic_rates.csv` | Clinic, month and booking source system | Known-outcome no-show rates and missing/unrecognized outcomes; useful for checking the migration-era data-capture signal |
| `brief_d/brief_d_chance_reference.csv` | Selection rule | The highest raw-rate clinic and the clinic with the largest conditional statistic, with shuffle reference details |
| `brief_d/brief_d_clinic_rates.png` | Chart | Clinic volumes versus raw no-show rate with 95% Wilson intervals |

Regenerate with the command in [`docs/brief-d-no-show-analysis.md`](../docs/brief-d-no-show-analysis.md). The full cleaned data is not committed. Outputs are aggregate counts only and contain no booking identifiers.
